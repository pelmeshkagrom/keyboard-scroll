## Features
- Switch through pages, scroll up and down using keyboard
- Switch through pages using Modifier Key (Shift by default) + MWheelUP/MWheelDown

## Default keybinds
- Scroll Up: W
- Scroll Down: S
- Next Page: D
- Previous Page: A
- Modifier Key: Shift

## Configuration
- Every keybind can be customized in the mod settings
- Horizontal mouse scroll feature can be enabled/disabled
- Configurable keyboard scroll sensitivity (when scrolling up/down)

### Known limitations
- Page switching (A/D) supports most major menus, but may not work in certain specific layouts.
- Custom page buttons from other mods may not be supported due to different unique Node IDs (e.g., `author.mod-name/button-id`).
